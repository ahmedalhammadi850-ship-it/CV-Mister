- [Phantom-page guard overflow clip bug](phantom-page-overflow.md) — Phantom guard removing a break can cause the preceding page to exceed PAGE_H, clipping real content. Fix: check totalHeight-prevBreakStart > prevPageVisibleH before removing any break (both LivePreview.jsx and puppeteerPdf.js).
- [PDF font timing bug — missing lines at page ends](pdf-font-timing-bug.md) — pageBreaks must be computed from the SAME post-font DOM state as captureEl.innerHTML. Fix: freshMeasure() in LivePreview exposes a post-font remeasure; CVBuilder calls it before download. LivePreview measure effect now does two passes (fast pre-font + accurate post-font).
