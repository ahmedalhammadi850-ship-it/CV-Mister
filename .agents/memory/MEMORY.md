- [Font proxy UA + Content-Type bug](font-proxy-bug.md) — Truncated UA in font-proxy → Google Fonts returns TTF; hardcoded font/woff2 Content-Type on font-file → Chromium rejects fonts silently → PDF has no text. Fix: full Chrome UA in proxy, detect extension for Content-Type.
- [Puppeteer CORS null-origin font block](puppeteer-cors-null-origin.md) — Puppeteer Chromium sends literal string "null" as Origin when fetching @font-face URLs; isCorsAllowed(!origin) misses it. Fix: also allow origin === "null" in CORS check.
- [PDF guard-pixel hidden heading bug](pdf-guard-pixel-bug.md) — The 8px backward-shift + guardPx in _buildDocument hid the first heading of page 2. Fix: use Math.round(start) as translateY, no guard overlay.
- [Pagination MARGIN dead-zone fix](pagination-margin-deadzone.md) — Pages 2+ have 48px top MARGIN; rawBreak must use pageVisibleH = PAGE_H-MARGIN (1074) not PAGE_H (1122). Wrong value causes 33px dead zone where content is invisible. Also: MIN_PHANTOM_PAGE reduced 120→50, totalSliceHeight capped at 1122 for all pages.
- [Phantom-page guard overflow clip bug](phantom-page-overflow.md) — Phantom guard removing a break can cause the preceding page to exceed PAGE_H, clipping real content. Fix: check totalHeight-prevBreakStart > prevPageVisibleH before removing any break (both LivePreview.jsx and puppeteerPdf.js).
- [Phase 3 ancestor guard — split container bug](phase3-ancestor-guard.md) — Phase 3 greedy fill can split a break-inside:avoid container by including its sub-elements (heading+title) while leaving its content (description) on page 2. Fix: skip elements that are descendants of unbreakable containers (containers whose bot > rawBreak).
- [PDF font timing bug — missing lines at page ends](pdf-font-timing-bug.md) — pageBreaks must be computed from the SAME post-font DOM state as captureEl.innerHTML. Fix: freshMeasure() in LivePreview exposes a post-font remeasure; CVBuilder calls it before download. LivePreview measure effect now does two passes (fast pre-font + accurate post-font).
- [Calibri causes 80-100px PDF page-break drift](calibri-font-drift.md) — Calibri is Windows-only; browser uses it but Puppeteer/Linux falls back to Inter → ~83px layout drift → 100px blank at page bottom. Fix: templateUtils.js uses Inter directly when fontFamily==='Calibri'; default font changed to Inter.
- [Phase 4 line-snap must run FIRST](phase4-first.md) — Old order (Phase1 pull → Phase4 snap) left 80-100px gaps. New order: Phase4 targets rawBreak first; Phase1 micro-pulls only (≤15px). Both LivePreview.jsx and puppeteerPdf.js must stay in sync.
- [Phase 3 heading orphan bug](phase3-heading-orphan.md) — Phase 3 greedy fill advances bestBreak past break-after:avoid headings, orphaning them at page bottom; heading then gets clipped in PDF. Fix: in Phase 3 loop, break out when encountering an element with break-after:avoid (both LivePreview.jsx and puppeteerPdf.js).
- [Phantom-page CLIP_TOLERANCE fix](phantom-clip-tolerance.md) — MIN_PHANTOM_PAGE=200 triggers phantom guard but safety check blocks removal when totalHeight > PAGE_H by template padding (~58px). Fix: add CLIP_TOLERANCE=60; if overflow ≤ 60px remove the break (clips only bottom padding). Must pass CLIP_TOLERANCE into puppeteerPdf page.evaluate() args.
