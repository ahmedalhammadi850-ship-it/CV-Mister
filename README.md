# CV Mister — AI-Powered Resume Builder

Build professional, ATS-optimized resumes in minutes. Choose from premium templates, customize every detail, and export to PDF instantly. Supports English and Arabic (RTL).

## Features

- Multiple CV templates (Modern, Elite, ATS-friendly, Arabic)
- AI-powered content rewriting
- PDF export (client-side + server-side Puppeteer for ATS)
- Subscription plans (Free / Pro / Business)
- Arabic & English support with RTL layout
- Admin dashboard

## Tech Stack

- **Frontend:** React 19, Vite 8, Tailwind CSS 4, Framer Motion
- **Backend:** Express 5, Firebase Admin, Firestore
- **PDF:** Puppeteer (ATS templates), html-to-image (standard templates)

## Development

```bash
npm install
npm run dev
```

App runs on `http://localhost:5000`
