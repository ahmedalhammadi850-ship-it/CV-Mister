أوقف أي تحسينات أو ميزات جديدة فوراً.

هذه مشكلة حرجة في نظام تصدير PDF للسيرة الذاتية ولم يتم حلها حتى الآن.

المشكلة:
ما زال يتم فقدان أو اختفاء أسطر في نهاية الصفحات أثناء تصدير PDF في جميع القوالب، رغم وجود إصلاحات سابقة.

---

## ❗ شرط العمل الإلزامي (NON-NEGOTIABLE)

ممنوع الانتقال لأي خطوة أو اعتبار المشكلة “محلولة” قبل تحقيق التالي:

---

# 1. Root Cause Analysis (إلزامي)
حدد السبب الحقيقي الدقيق فقط، ويجب أن يكون واحد من التالي أو ما يعادله:

- mismatch بين Preview rendering و Puppeteer rendering
- reflow يحدث بعد حساب pageBreaks
- اختلاف font metrics بين البيئتين
- قياس height قبل استقرار layout
- أو سبب محدد آخر موثق من الكود

❗ ممنوع تقديم حلول قبل تحديد السبب الحقيقي بدقة.

---

# 2. إثبات السبب (Evidence Required)

يجب تقديم دليل من الكود على:
- أين يتم حساب pageBreaks
- متى يتم أخذ DOM snapshot
- متى يتم تحميل الخطوط
- أين يحدث اختلاف الزمن (timing mismatch)

---

# 3. إصلاح جذري واحد فقط (NOT PATCHES)

ممنوع:
- حلول متعددة
- تحسينات صغيرة
- tweaks للأرقام

المطلوب:
👉 حل واحد جذري يزيل السبب من جذوره

---

# 4. تثبيت النظام (Critical Requirement)

يجب ضمان:

- Preview و PDF يستخدمان نفس pagination snapshot 100%
- لا يوجد إعادة حساب pageBreaks في أي مرحلة لاحقة
- لا يوجد recalculation داخل Puppeteer
- لا يوجد اختلاف DOM بين المرحلتين

---

# 5. Page Break Rule النهائي (Strict)

if (currentY + elementHeight + 15px > PAGE_HEIGHT)
→ move FULL element to next page

ممنوع تماماً:
- تقسيم عنصر
- قص عنصر
- إعادة ترتيب بعد الحساب

---

# 6. منع فقدان النص (CRITICAL BUG)

تحقق من ومنع:
- clipping في نهاية الصفحة
- overflow hidden يقطع النص
- subpixel rendering loss
- آخر سطر غير مرئي في PDF فقط

---

# 7. شرط النجاح الإجباري

لا تعتبر المهمة منتهية إلا إذا:

✓ تم تحديد root cause بشكل واضح
✓ تم تطبيق fix واحد جذري
✓ تم إثبات أن Preview = PDF 100%
✓ تم اختبار جميع القوالب
✓ لم يحدث فقدان حتى حالة واحدة

---

## ❗ ممنوع إنهاء المهمة بدون إثبات عملي

إذا لم يتم حل المشكلة فعلياً، يجب العودة للتشخيص وعدم الانتقال لأي خطوة أخرى.
